## About

This repository brings scripts together in one place, with folders organized around the games or categories they relate to. Most of the scripts are open source and were collected from a Discord channel. I have fixed some of them, and I am currently the only person working on this project.

The collection includes game-specific folders, multi-game and universal categories, and folders for related source files and libraries. Folder contents may change as the repository is updated.
