# TRB Scripts

A collection of scripts organized by game and category. Most scripts in this repository are open source and were collected from a Discord channel. I have fixed some of them, and I am currently the only person working on this project.

## Repository contents

Scripts are grouped into folders, including:

- `axelhub`
- `bladeball`
- `bloxfruits`
- `bloxstrike`
- `doors`
- `ftap`
- `gag` and `gag2`
- `mm2`
- `multigame`
- `rivals`
- `sniperarena`
- `universal`
- `random`
- `fixedlibs` and `src`

Folder contents may change as the repository is updated.
