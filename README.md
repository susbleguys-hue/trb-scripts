A community-collected collection of Lua scripts, organized by game and category.

About
This repository brings scripts together in one place, with folders organized around the games or categories they relate to. Most scripts are open source and were collected from a Discord channel. I've fixed some of them and am currently the only person maintaining this project.

The collection includes game-specific folders, multi-game and universal categories, and folders for related source files and libraries. Folder contents may change as the repository is updated.

How to Use
Open the folder for the game you want.

Open the script file.

Copy the code.

Paste it into your executor and run it.

No installation or dependencies required.

Status Legend
Individual scripts may be marked with one of the following:

Marker	Meaning
✅	Working — tested and functional
⚠️	Buggy — usable but has known issues
❌	Broken — does not work as intended
If a script has no marker, it has not been recently tested.
