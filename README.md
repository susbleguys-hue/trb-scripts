## Overview

This repository brings together Lua scripts and supporting files from multiple Roblox games and utility categories. The goal is to make it easier to find, browse, and use scripts in one central place.

Most scripts are collected from community sources and Discord discussions, then organized into folders by game or category. Some files have been fixed, cleaned up, or adapted by the repository maintainer, but the original creators are still credited where applicable.

## Features

- Game-specific folders for popular Roblox experiences
- Multi-game and universal script categories
- Supporting libraries and source files
- Simple copy-and-paste workflow for Roblox executors
- No installation or setup required

## How to Use

1. Open the folder for the game or category you want.
2. Open the script file you want to use.
3. Copy the code.
4. Paste it into your Roblox executor.
5. Run the script and test it in-game.

No installation or dependencies are required.
